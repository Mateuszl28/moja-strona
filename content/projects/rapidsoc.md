## O projekcie

Rapidsoc to drugi z moich projektów konkursowych. Powstał pod presją czasu, więc to dobra lekcja **focus + delivery** zamiast dopieszczania szczegółów.

## Stack

Klasyczny "ship fast" stack:

- **Next.js** — App Router, server components
- **TypeScript** — bo bezpieczniej
- **Tailwind CSS** — styling bez przerywników
- **Vercel** — deploy w minutę

## Czego się nauczyłem

- **Time-boxing działa.** Bez deadlinu projekt rośnie w nieskończoność.
- **Refactor po deploy.** Najpierw działające MVP, potem czyszczenie.
- **Dokumentacja przyspiesza, nie spowalnia.** README zmusza do zrozumienia własnego projektu.
